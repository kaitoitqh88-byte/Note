How to Use

  1. Go to the Search Tool
  2. Click on the "Cloudflare DNS" tab
  3. The interface will load with Cloudflare-specific options
📸 Screenshot of Cloudflare DNS tab would go here

Domain Input:
  • Enter domain name (e.g., example.com)
  • Domain must be managed in your Cloudflare account
Configuration Options:
  • Include Proxied Records: Show both proxied and DNS-only records
  • Active Records Only: Filter out inactive/disabled records
  • Compare with Public DNS: Enable DNS comparison feature
Example Configuration:
Domain: yoursite.com
✅ Include Proxied Records
✅ Active Records Only
✅ Compare with Public DNS

DNS Records Display:
A Records AAAA Records CNAME Records MX Records TXT Records
Proxied through Cloudflare
DNS Only
Comparison Results:
Matches: Records that resolve identically
Mismatches: Different resolution results
CF Only: Records only in Cloudflare

API Integration

Use these endpoints to integrate Cloudflare DNS lookup into your applications:

Cloudflare DNS Lookup
Endpoint: GET /index.php?action=cloudflare-dns
Parameters:
domain - Domain name to lookup
include_proxied - Include proxied records (true/false)
show_only_active - Active records only (true/false)
compare_dns - Enable comparison (true/false)
Response Format
{
  "success": true,
  "data": {
    "zone_id": "abc123...",
    "domain": "example.com",
    "cloudflare_records": {...},
    "comparison": {...},
    "statistics": {...}
  }
}
Requirements
  • Cloudflare account with API access
  • Valid Cloudflare API token
  • Domain(s) managed in Cloudflare
  • PHP 7.4+ with cURL support

Troubleshooting

Issue Possible Cause Solution
"Domain not found in Cloudflare" Domain not in your CF account Verify domain is added to your Cloudflare account
"Cloudflare API Error" Invalid API credentials Check CLOUDFLARE_API_TOKEN in config.php
"No DNS records found" Domain has no DNS records Add DNS records in Cloudflare dashboard
DNS comparison shows errors Public DNS not yet propagated Wait for DNS propagation (up to 24-48 hours)
