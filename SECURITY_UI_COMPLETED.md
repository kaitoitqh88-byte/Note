## 📋 **Usage Guide**

### **Quick Start**
```bash
# 1. Copy files to web directory
cp security_manager.php /var/www/html/
cp -r assets/ /var/www/html/assets/

# 2. Configure Cloudflare credentials
vim config.php

# 3. Set proper permissions
chmod 644 *.php assets/css/*.css assets/js/*.js
chmod 755 assets/ assets/css/ assets/js/

# 4. Access via browser
http://yourdomain.com/security_manager.php
```

### **Demo Preview**
```bash
# View demo without backend setup
```
