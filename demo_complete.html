Quick API Test

Test Cloudflare DNS API ngay bây giờ

JavaScript Example

// Lấy DNS Records từ Cloudflare
fetch('/Note/index.php?action=cloudflare-dns&domain=example.com')
  .then(response => response.json())
  .then(data => {
    if (data.success) {
      console.log('DNS Records:', data.data.cloudflare_records);
      console.log('Statistics:', data.data.statistics);
    }
  });

cURL Example

# Test API với cURL
curl -X GET \
  "http://localhost/Note/index.php?action=cloudflare-dns&domain=example.com&include_proxied=true" \
  -H "Accept: application/json"

# Parse với jq
curl -s "..." | jq '.data.statistics'
