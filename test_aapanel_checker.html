Thông tin kỹ thuật
  • Kiểm tra HTTP/HTTPS response
  • Đo response time
  • Phát hiện trang aaPanel
  • Kiểm tra form login
  • Xử lý SSL/TLS
  • Timeout protection
Định dạng file aapanel.txt

File aapanel.txt chứa thông tin tài khoản với định dạng:

URL_AAPANEL    USERNAME    PASSWORD
https://103.213.216.172:17806/31daf524    admin    password123
http://142.91.102.248:40034/6769e3f9    user1    mypassword

Mỗi dòng chứa URL aaPanel, username và password được phân cách bằng tab hoặc khoảng trắng

Kết quả kiểm tra
✅ Thành công:
  • Status code (200, 302, etc.)
  • Response time (ms)
  • Phát hiện trang aaPanel
  • Form login có sẵn
  • Kích thước response
❌ Thất bại:
  • Chi tiết lỗi kết nối
  • Timeout hoặc unreachable
  • SSL/certificate issues
  • Server không phản hồi
  • Port bị chặn
