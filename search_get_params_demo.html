✅ Search Form với GET Parameters

🎯 Tính năng mới: Form tự động fill từ URL

Đã hoàn thành: Search form giờ tự động lấy giá trị từ URL parameters!
  • ✅ Search Input: Lấy từ ?q=value
  • ✅ Status Filter: Lấy từ ?status=active
  • ✅ Per Page: Lấy từ ?per_page=50
  • ✅ Use Cache: Lấy từ ?use_cache=on
  • ✅ Bulk Mode: Lấy từ ?bulk=on

🔗 Test URLs - Click để thử

Basic Tests:
🌐 Trang search thường Default values, không có parameters 🔍 Search "test" Ô search sẽ có sẵn "test" 🎯 Search "example" + Active status Cả search input và status filter sẽ được set
Advanced Tests:
⚡ Full parameter test Search + Status + Per Page 🚀 Tất cả parameters Tất cả form fields sẽ được pre-fill 📋 Empty search Query trống (hiển thị tất cả)

📚 URL Examples - Copy & Paste vào address bar

🔍 Basic search:
http://localhost/index.php?action=search&q=example.com
🎯 Search với filter:
http://localhost/index.php?action=search&q=test&status=active&per_page=50
⚙️ Advanced options:
http://localhost/index.php?action=search&q=domain&status=pending&per_page=100&use_cache=on&bulk=on
🌐 Wildcard search:
http://localhost/index.php?action=search&q=*.com&status=active
