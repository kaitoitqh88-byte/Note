Chức Năng Mới: Domain Status Checker

Tính năng kiểm tra tình trạng domain với các thông tin chi tiết:

  • Trạng thái zone: Active, Pending, Error
  • DNS Records: A, AAAA, CNAME, MX records
  • SSL Status: Tình trạng chứng chỉ SSL
  • Security Settings: Các thiết lập bảo mật
  • Plan Information: Gói dịch vụ Cloudflare
✅ Features Implemented:
  • Bulk domain status checking (up to 20 domains)
  • Domain parsing from multiple formats
  • DNS records analysis
  • SSL certificate status check
  • Comprehensive summary statistics
  • Detailed results table with expandable info

Format nhập liệu hỗ trợ:

  • Mỗi domain trên một dòng
  • Cách nhau bằng dấu phẩy
  • Cách nhau bằng dấu chấm phẩy
  • Hoặc kết hợp các cách trên
📊 Kết Quả Hiển Thị:
Thông Tin Mô Tả Biểu Tượng
Zone Status Trạng thái domain trên Cloudflare Active Pending
DNS Records Có DNS records được cấu hình
SSL Status Chứng chỉ SSL có được bật
Plan Type Gói dịch vụ Cloudflare đang sử dụng Free, Pro, Business, Enterprise
Details Chi tiết DNS records, thời gian tạo
Lưu Ý:
  • Chỉ kiểm tra được domain có trong Cloudflare account của bạn
  • Tối đa 20 domain cho mỗi lần check để tránh quá tải API
  • Kết quả có thể được cache để tăng tốc độ
  • Domain không tồn tại sẽ hiển thị "Not Found"
Test Instructions
  1. Mở Domain Status Checker: Click vào button bên dưới
  2. Nhập domain list: Paste danh sách domain vào textarea
  3. Submit form: Click "Check Tình Trạng Domain"
  4. Xem kết quả: Kiểm tra summary và detail table
  5. Expand details: Click icon info để xem chi tiết
