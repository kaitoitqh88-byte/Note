## 💡 **Usage Examples**

### 🚀 **Quick Start**
```bash
# Method 1: Main Launcher (Recommended)
php portable_launcher.php
→ Choose option 7: Security Rule Manager
→ Choose option 1: Create Custom Rule

# Method 2: Standalone  
start_security_rules.bat     # Windows
./start_security_rules.sh    # Unix/Linux
php CloudflareSecurityRuleManager.php  # Direct
```

### 🎯 **Example Workflow**
```
1. Create Custom Rule
   Domain: example.com
   Name: Block Bot Traffic
   Expression: (http.user_agent contains "bot" and ip.geoip.country eq "CN")
   Action: Block
   Priority: 100
   → Rule created successfully!
```

### 📚 **Template Examples**
- **Country blocking**: `(ip.geoip.country eq "CN")`
- **Bot protection**: `(http.user_agent contains "malbot")`  
- **Rate limiting**: `(rate(1m) > 100)`
- **Path protection**: `(http.request.uri.path contains "/admin")`
- **Domain-specific**: `(http.host eq "api.example.com")`
