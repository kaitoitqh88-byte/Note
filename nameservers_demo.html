Cloudflare Nameservers Feature Added!

Domain Status Checker giờ hiển thị thông tin Cloudflare Nameservers trong kết quả.

Nameservers Display Features
✅ Table View:
  • Shows first nameserver prominently
  • Displays count of additional nameservers
  • Compact format: name.ns.cloudflare.com
  • Count indicator: +1 more
Example:
aron.ns.cloudflare.com
+1 more
📋 Detailed View:
  • Complete list of all nameservers
  • Each nameserver on separate line
  • Blue color coding for visibility
  • Accessible via info icon click
Example:
aron.ns.cloudflare.com uma.ns.cloudflare.com

Tại sao hiển thị Nameservers?
  • Verify DNS delegation: Kiểm tra domain có đang point về Cloudflare không
  • Troubleshoot issues: Debug các vấn đề DNS và configuration
  • Quick reference: Xem nhanh nameservers mà không cần vào dashboard
  • Domain migration: Hỗ trợ việc migration domain giữa các provider
